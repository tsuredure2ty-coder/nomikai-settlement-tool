# 飲み会清算ツール

## 2026-10-28 新版（v5）

- 役職・勤務形態・性別の傾斜、自由な固定額、嘱託の登録に対応。
- メンバーと配分のテンプレート、会社補助、幹事・端数調整、集金済みチェック。
- 金額を確定して保存する直近5回の履歴と、次の会への流用。
- メール・パスワードのログインと、本人のPC・スマホ間のクラウド同期。
- 既存の端末データは保持し、旧画面は `legacy.html` から利用可能。

`public-config.js` は公開してよい接続先URLとpublishable/anonキーだけを含みます。パスワード・認証トークン・清算データはリポジトリに含めません。清算データはSupabaseの本人専用アクセス制御を通して扱います。

以下は旧版の利用方法・更新記録です。

会社の飲み会向けの、HTML/CSS/Vanilla JavaScriptだけで動く清算ツールです。

## 使い方

`index.html` をブラウザで開くだけで使えます。サーバーやデータベースは不要です。

## 主な機能

- 名前付き参加者テンプレート3枠
- 上司などの金額固定と、残額を多め・少なめの円単位で調整
- 固定額0円による免除と、当日の不参加の切り替え
- 固定額・免除を守る端数調整と、合計が一致しない場合のコピー停止
- スマホ向けの参加者一覧・折りたたみ編集・下部の差額表示
- 直前に削除した参加者の取り消し
- LINE用コピー、端末内の自動保存、バックアップ保存・復元
- 以前の役職倍率による配分との互換

## 保存について

「端末保存」や参加者テンプレは、利用中のブラウザの LocalStorage に保存されます。GitHubやサーバーには送信されません。別のPCや別のブラウザでは共有されません。

## 補足

通信先を持たないローカル完結の作りです。保存データは利用中の端末内にのみ保存されます。

### 基本の操作

1. 3枠からテンプレートを選び、「呼び出す」で参加者を読み込みます。初回は参加者を追加して、任意の枠に名前を付けて保存します。
2. 総額を入力します。新しい清算の分け方は「金額で調整」です。
3. 上司など、支払額を決めた人の「金額を固定」に入力します。空欄は自動計算、0円は免除です。
4. 自動計算の人は「多め・少なめの差」と「差を±500円」で調整します。差は丸め前の基準額からの目安で、最終支払額は丸めと端数調整で変わります。支払額を厳密に決める場合は金額を固定してください。
5. 不参加の人は「今回参加する」を外します。テンプレートから削除せずに計算・LINE用テキストから除外できます。
6. 合計と各人の金額を確認し、LINE用コピーを使います。送信はこのツールでは行いません。

固定額は丸めず、端数調整にも使いません。自動計算の人へ丸め単位を配り、その単位未満の端数だけを幹事優先・役職優先・均等の設定で調整します。幹事が固定額・免除・不参加なら、ほかの自動計算の人を対象にします。配分先がない、固定額合計が総額を超える、小数円などのときは案内を表示してコピーを止めます。

### データの保護

- 旧保存データは読み込み、新形式へ保存します。以前の保存キーは削除しません。旧データは倍率方式を引き継ぎ、画面で金額方式へ切り替えられます。丸め処理は新しい計算に変わるため、旧版と最終支払額が変わることがあります。
- 以前の参加者テンプレートは1枠目へ読み込みます。3枠への保存では以前の保存キーを残します。
- テンプレートには名前・役職・通常の配分設定・固定額・幹事を保存します。当日の不参加・遅刻・早退は呼び出し時に解除します。手動倍率は保持します。
- 呼び出し・上書き・リセット・バックアップ復元は、画面内で確認してから実行します。リセットしても3枠のテンプレートは残ります。
- 削除の取り消しは直前の1人が対象です。その後ほかの人を編集しても、その編集を戻しません。取り消しは再読み込み、テンプレート呼び出し、リセット、バックアップ復元で終了します。
- 保存失敗は成功と表示しません。読み込めない保存データは勝手に消さず、上書きを止めて保護します。
- 「保存・バックアップ・リセット」からバックアップを保存できます。ファイル保存が利用できない場合は画面の保存用内容をコピーして保管し、貼り付けから復元できます。バックアップには現在の入力・3枠・移行前の保存内容が含まれます。

### 今回の更新を戻す手順

公開用リポジトリの作業内容を保存し、最新の `main` を取得したうえで、今回の更新コミットを取り消します。履歴を残したまま復帰するため、強制pushは使いません。

```sh
git switch main
git pull --ff-only origin main
git revert --no-edit v4-mobile-20261008
git push origin main
```

GitHub Pagesの配信完了後に画面を再読み込みしてください。旧版のソースは復帰用タグから参照できます。

旧版へ戻す前に、スマホ対応版の「保存・バックアップ・リセット」から保存内容をバックアップしてください。旧版の保存キーは残していますが、旧版は新形式の入力や3枠を読み込めず、移行前の保存内容を表示します。新しい入力をそのまま旧版へ持ち越す操作ではありません。
